# docs/img

The README references `docs/img/gate.png`. Capture it before publishing — it is
the single highest-value addition for a visual product, and the one thing a
logged-out visitor uses to understand what TheoryTracker is.

## What to capture

The gate working: the **same series** at two reading positions, side by side.

1. Run the quick start (`README.md`) so the demo series is seeded.
2. Open two browser sessions (e.g. a normal window and a private window):
   - log in as `cora@example.com` (READER, early in book 1), and
   - log in as `alice@example.com` (OWNER, finished the series).
3. Open the **same series' card grid** in both. Cora sees rows of locked grey
   tiles where Alice sees the actual cards.
4. Screenshot both grids next to each other (or stitch two shots). Crop to the
   card grids; no browser chrome needed.
5. Save as `docs/img/gate.png` and delete this file (or leave it — harmless).

Keep it reasonably sized (< ~500 KB); it ships in every clone.
